# Cymbol
A set of simple header only libraries and executables for trivial stuff

cymbol.h:
    header for packing/unpacking data, and some basic util on ctypes

cymath.h:
    header for some basic math functionality

finspect.c:
    executable for inspecting file data

toc.c:
    executable that writes images in .c format (needs stb_image.h)

pythum.py:
    simple library for simple quantum circuit building and simulation, check QuantumCircuit class in file for example usage (not optimized)
